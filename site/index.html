Breaking the chain: npm & GitHub Actions

1 npm install-scripts demo (local)

Run -Prep once on good wifi to cache npm 11 & 12. Needs Node ≥ 24.15 for npm 12. Older Node still blocks, but prints an engine warning.

cd C:\Code\GHJ\demos\supply-chain\npm-install-scripts; .\run-demo.ps1 -Prep
cd C:\Code\GHJ\demos\supply-chain\npm-install-scripts; .\run-demo.ps1
node -v
  • Act 1 · npm 11: postinstall harvests the (fake) NPM_TOKEN. It would exfiltrate and re-publish.
  • Act 2 · npm 12: same install, and the script is blocked. Review with npm install-scripts ls.
  • Line: “The single highest-impact default change: the easy door is now closed.”
